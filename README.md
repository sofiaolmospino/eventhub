# EventHub

Plataforma para la gestión y promoción de eventos de entretenimiento, principalmente fiestas, boliches y eventos nocturnos.

## 1. Problema

Actualmente la información sobre fiestas y eventos se encuentra dispersa entre redes sociales, mensajes y diferentes medios de venta. Esto puede dificultar la consulta de eventos, la compra y control de entradas, la reserva de mesas y la gestión de las ventas realizadas por revendedores.

## 2. Objetivo del MVP

Construir una plataforma que permita gestionar eventos de entretenimiento, consultar eventos disponibles, administrar entradas, registrar compras, gestionar reservas de mesas y controlar productos y ventas asociados a los eventos.

## 3. Actores principales

- Administrador
- Organizador
- Cliente
- Revendedor

## 4. Alcance inicial

- Gestión de usuarios y roles
- Gestión de eventos
- Gestión de locales
- Gestión de entradas y tipos de entrada
- Compra y control de entradas
- Gestión y reserva de mesas
- Gestión de productos
- Registro de pedidos
- Gestión de revendedores y ventas de entradas
- Consulta de información básica de ventas y eventos

## 5. Fuera de alcance

- Integración con sistemas bancarios reales
- Facturación fiscal
- Control mediante cámaras o reconocimiento facial
- Sistemas físicos de acceso al boliche
- Geolocalización en tiempo real
- Inteligencia artificial para determinar precios o autorizar accesos
- Integración automática con redes sociales

## 6. Stack objetivo del semestre

- Backend: Java 21 + Spring Boot
- Base de datos: PostgreSQL + Flyway
- Web: React + TypeScript
- Móvil: React Native + TypeScript
- Pruebas API: Postman
- Contenedores: Docker / Docker Compose
- Versionado: Git + GitHub
- CI: GitHub Actions
