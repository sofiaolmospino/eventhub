# Glosario v0.1 — EventHub

| Término | Significado inicial |
|---|---|
| Evento | Fiesta, concierto, festival o actividad de entretenimiento registrada en la plataforma. |
| Local | Lugar físico donde se realiza un evento. |
| Entrada | Acceso que permite a una persona asistir a un evento. |
| Tipo de entrada | Categoría de acceso a un evento, como general, VIP o preventa. |
| Cliente | Persona que consulta eventos, compra entradas o realiza reservas. |
| Organizador | Persona responsable de crear y gestionar un evento. |
| Revendedor | Persona autorizada para comercializar entradas de un evento. |
| Mesa | Espacio dentro de un local que puede ser reservado para un evento. |
| Reserva | Registro mediante el cual un cliente solicita y asegura una mesa para un evento. |
| Producto | Bebida, comida u otro artículo que puede ser ofrecido durante un evento. |
| Pedido | Solicitud de uno o varios productos realizada durante un evento. |
| Venta de entrada | Registro de una entrada comercializada por un revendedor. |
| Comisión | Monto o porcentaje que corresponde al revendedor por una venta de entrada. |
| QR | Código asociado a una entrada que puede utilizarse para identificarla y validar el acceso. |
| Estado | Condición actual de una entidad, como disponible, reservada, cancelada o activa. |

> Este glosario corresponde a la versión inicial del dominio. Los significados podrán refinarse cuando se definan nuevas reglas de negocio, y los cambios importantes deberán quedar documentados.
