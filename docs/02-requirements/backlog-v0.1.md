# Backlog v0.1 — EventHub

## Convención de prioridad

- P0: imprescindible para el flujo crítico del MVP.
- P1: importante para completar la operación.
- P2: complemento posterior.

### EH-001 — Consultar eventos

**Prioridad:** P0

Como cliente, quiero consultar los eventos disponibles para conocer sus fechas, horarios, locales y tipos de entrada.

### EH-002 — Registrar evento

**Prioridad:** P0

Como organizador, quiero registrar un evento para poder publicarlo y gestionar su información.

### EH-003 — Gestionar entradas

**Prioridad:** P0

Como organizador, quiero definir los tipos y precios de las entradas para controlar los accesos disponibles para cada evento.

### EH-004 — Comprar entrada

**Prioridad:** P0

Como cliente, quiero comprar una entrada para asegurar mi acceso al evento.

### EH-005 — Reservar mesa

**Prioridad:** P0

Como cliente, quiero reservar una mesa para asegurar un espacio dentro del evento.

### EH-006 — Gestionar productos

**Prioridad:** P1

Como organizador, quiero registrar los productos disponibles para poder gestionar las bebidas y comidas ofrecidas durante el evento.

### EH-007 — Registrar venta de entrada

**Prioridad:** P1

Como revendedor, quiero registrar las entradas que comercializo para llevar un control de mis ventas y comisiones.

### EH-008 — Consultar ventas

**Prioridad:** P1

Como organizador, quiero consultar las ventas de entradas para conocer el movimiento comercial de mis eventos.

### EH-009 — Registrar pedidos

**Prioridad:** P1

Como cliente, quiero registrar un pedido de productos durante un evento para solicitar las bebidas o comidas disponibles.

### EH-010 — Consultar información del evento

**Prioridad:** P2

Como cliente, quiero consultar información detallada del evento para decidir si quiero asistir.
